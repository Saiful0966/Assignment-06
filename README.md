#  FitLog — Train With Intent

FitLog is a modern, responsive web application designed to help fitness enthusiasts track workouts, manage daily training plans, and stay consistent with their fitness goals. Built with a sleek dark-mode UI, it provides an intuitive interface for exploring exercises and customizing daily routines.

##  Technologies Used

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Notifications:** React Hot Toast
* **Version Control:** Git & GitHub


##  Key Features

1. ** Comprehensive Workout Library**
   Explore an extensive catalog of exercises filtered by target muscle groups (Chest, Arms, Legs, Core, Shoulders, Full Body) with detailed workout breakdowns.

2. ** Custom Daily Plan Management**
   Seamlessly add or remove exercises to build and organize your personalized daily training routine.

3. ** Saved Workouts & Favorites**
   Save your favorite routines and exercises for quick access whenever you are ready to train.

4. ** Real-Time Toast Notifications**
   Get instant visual feedback when adding, removing, or updating items in your workout plan.

5. ** Fully Responsive Dark-Mode UI**
   Enjoy a clean, dark-themed user experience designed to look great across desktop, tablet, and mobile devices.
